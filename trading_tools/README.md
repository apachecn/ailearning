# MES 日内交易员工具包（上班族 · $4000 账户 · Al Brooks H2/L2 + Failed Breakout）

为北京时间上班族、使用 Micro E-mini S&P 500（MES）期货、专精 Al Brooks 的 H2/L2 + Failed Breakout 两个 setup 的小资金（$4000）日内交易员设计的 4 个 Excel 工具。

> ⚠️ 仅为个人交易纪律与复盘工具，不构成任何投资建议。期货交易有较高风险，可能导致超过本金的亏损。

## 文件结构

```
trading_tools/
├── xlsx_writer.py           纯标准库 xlsx 生成器（无需 pip 安装任何包）
├── build_tools.py           4 个工具的生成脚本
├── README.md                本文件
└── dist/                    生成的 Excel 文件（直接可用）
    ├── 1_h2l2_scoring_and_trade_log.xlsx
    ├── 2_premarket_checklist.xlsx
    ├── 3_position_calculator_mes_4000.xlsx
    └── 5_60day_tracker_and_setup_library.xlsx
```

## 四个工具速览

### 1. H2/L2 打分 + 交易日志
- **使用说明**：4 个维度打分逻辑、L2 镜像规则、Failed Breakout 补充、风控硬规则
- **打分模板**：入场前的 4 维度打分表（趋势 / 结构 / 回调 / 信号 bar），总分 ≥75 才入场，20 行待填
- **交易日志**：60 行，自动计算止损点数、目标点数、R:R、盈亏 $（按 MES $5/点），底部自动汇总胜率/累计 R/执行分均值等 8 项指标

### 2. 开盘前 Checklist
- **每日 Checklist**：身心状态 / 事件风险 / 技术面 / 交易计划 / 软硬件 / 心理最后一问，共 6 大类 38 项
- **关键价位表**：60 天的前日高低、隔夜高低、VIX 记录
- **事件日历参考**：FOMC / CPI / NFP / 财报 / OPEC 等 10 类高风险事件及规避策略

### 3. 仓位计算器（$4000 MES 专用）
- **仓位计算器**：输入账户净值、单笔风险 %、止损点数 → 自动输出建议合约数、实际风险 $ / %、1R/1.5R/2R 盈利预估；6 项自动安全检查；日内熔断跟踪器（亏损/盈利/连亏状态自动判断）
- **场景速查表**：$2000–$20000 账户 × 3–20 点止损的建议合约数矩阵（风险 2% 固定），红/绿/蓝三色标记可执行性

### 4. 60 天追踪 + Setup 图库指南
- **60 天实盘追踪**：每日笔数 / 胜负 / R / $ / 执行分 / 规则违反 / 情绪分 / 睡眠分，自动累计净值曲线；底部 12 项 60 天汇总
- **阶段里程碑**：Day 1–10 到 Day 241+ 的 6 个阶段，各阶段目标 / 评估指标 / 失败退出标准
- **Setup 图库构建指南**：10 大主题（为何自建、数量目标、数据源、标注工具、6 元素、A/B/C 分级、复盘方法、特征清单、常见错误、7 天起步计划）
- **周复盘模板**：每周日 20 分钟 12 个标准问题

## 使用流程

### 每日流程（北京时间）

```
20:00–21:00   开盘前 1 小时
              ├─ 打开工具 2 的"开盘前 Checklist"，逐项打钩
              ├─ 记录工具 2 "关键价位表"当日一行
              └─ 任何一项不通过 → 当晚不交易

21:30 / 22:30 美股开盘（夏令时 / 冬令时）
              ├─ 前 15 分钟只观察，不交易
              ├─ 发现 setup → 用工具 1 打分 → ≥75 进场
              └─ 进场前用工具 3 确认合约数（务必≤2张对于$4000）

23:00–23:30   收官
              ├─ 达到 +1.5R → 停手
              ├─ 触及日亏损上限 → 立即停手
              └─ 当日在工具 1 "交易日志"填入每笔细节

23:30–24:00   复盘
              ├─ 每笔截图 + 上下文打分
              └─ 工具 4 "60 天追踪"填入当日汇总
```

### 每周日晚

```
工具 4 "周复盘模板" → 用 20 分钟回答 12 个问题
+ 整理本周 Setup 图库新增 2–5 张
```

### 每 30 天 / 60 天

```
对照工具 4 "阶段里程碑" 评估：
  - 执行分均值 ≥8？
  - 规则违反 ≤ 5 次？
  - 累计亏损是否超出阶段限制？
```

## 工具重新生成

所有 Excel 文件内容可以通过修改 `build_tools.py` 重新生成：

```bash
python build_tools.py
# → 输出到 dist/
```

`xlsx_writer.py` 使用纯 Python 标准库实现，无需安装 openpyxl / xlsxwriter 等依赖。

## 风控硬规则（刻在 DNA 里）

- 单笔风险 ≤ 账户 2% = $80
- 日亏损上限 4% = $160，触及立即停手
- 日盈利 ≥ +1.5R 后：剩余时段只平不开
- 绝不持仓过夜
- FOMC / CPI / NFP 当日：不交易
- 连亏 3 笔：强制冷却 1 小时
- 工作日疲劳：主动放弃当晚交易
